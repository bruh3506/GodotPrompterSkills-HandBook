# 专用服务器：无画面运行与多人架构

一句话：把 Godot 游戏配置为不渲染画面也能运行的服务器，并管理连接、房间和游戏流程。

## 通俗解释

专用服务器像一位不参与游戏的裁判：它持续运行规则并决定可信的游戏结果，但不显示玩家看到的画面。

## 场景例子

玩家加入一场对局后，服务器创建房间并生成角色；玩家断线时移除或暂存该角色；达到胜利条件后，服务器通知所有客户端结算并进入下一局。

## 专业要点

使用 headless 导出与服务器专用配置，服务端权威判定重要游戏状态。把连接、玩家生命周期、房间状态与对局逻辑分层；无渲染不等于自动安全，也不代表所有节点都适合在服务端执行。

## 什么时候用

需要长期运行的多人主机、房间管理或可信状态判定时使用。小型联机原型可先掌握 `multiplayer-basics`；本技能重点在服务器进程、部署与比赛生命周期。
