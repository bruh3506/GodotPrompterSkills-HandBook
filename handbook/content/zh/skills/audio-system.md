# 音频系统：总线、空间音效与音乐

一句话：把声音播放、分类混音和资源管理组织起来，让音频更容易调试和扩展。

## 通俗解释

音频总线像调音台的多个推子：脚步声、音乐和 UI 声音先进入各自通道，再统一调音量、加混响或静音。

## 场景例子

玩家进入洞穴后，音乐渐渐变暗，远处怪物的声音从左侧传来；连续击中敌人时，音效池复用已准备好的播放器，不必每次都临时创建一堆节点。

## 专业要点

用 `AudioStreamPlayer`、`AudioStreamPlayer2D/3D` 区分普通与空间化播放。音频 bus 负责混音和效果，空间衰减由播放器与环境设置决定。高频短音效适合池化；音乐切换需要控制淡入淡出、循环点和并发。

## 什么时候用

需要统一音量控制、空间音效、音乐切换或大量短音效时使用。声音由多个系统触发时，可通过信号解耦，但播放器和总线配置仍应有清楚归属。
