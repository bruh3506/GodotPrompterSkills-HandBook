# 背包系统：物品、格子、堆叠与装备

一句话：用 Resource 描述物品，用清晰 API 管理背包状态，再把 UI 和存档接到系统上。

## 通俗解释

物品定义像商品目录，背包实例像玩家手里的购物袋。目录说明“这是治疗药”，背包状态则记录有几瓶、放在哪个格子。

## 场景例子

玩家捡起第 2 瓶药水时，系统先查找已有堆叠是否有空位；没有才占用新格子。装备界面再把武器从背包槽位移到手持槽位。

## 专业要点

分开物品定义资源、运行时物品堆栈和槽位容器。先决定格子容量、堆叠规则、唯一物品标识和装备语义，再提供一致的添加/移除 API。UI 通过信号刷新，存档使用稳定的数据表示。

## 什么时候用

项目需要物品列表、堆叠、装备或背包 UI 时使用。少量固定拾取物不一定需要完整系统；物品数据资源设计可看 `resource-pattern`，存档序列化看 `save-load`。

## English learning

| English | 中文理解 | Example |
|---|---|---|
| item stack | 物品堆叠；一格中相同物品的数量 | Add the potion to an existing item stack.（把药水加进已有堆叠。） |
| equipment slot | 装备槽位 | Move the sword to the equipment slot.（把剑移到装备槽位。） |
